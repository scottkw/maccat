    does NOT filter them.
  - A degraded section has degraded=True (and items may be empty).
  - A legitimately empty section (including the WR-05 header) has items=[] and
    degraded=False.

  Injection-safety helpers (in their own separator block):
  - `quote_for_script(value: str) -> str` — returns `shlex.quote(value)`. Docstring: "Sole
    path catalog values enter shell command position."
  - `safe_comment_value(value: str) -> str` — strips `\n` and `\r` via `.replace()`. Docstring
    must explain WHY: shlex.quote does NOT strip embedded newlines; a newline in a # cataloged:
    comment breaks the comment line and exposes the remainder as a live shell command.

  Section renderers (in their own separator block):

  `_should_skip(section: ParsedSection) -> bool`
    Returns True if `section.degraded` OR `len(section.items) == 0`.

  `_checklist_display(item: ParsedItem) -> str`
    Returns `"  - {safe_comment_value(name)} ({safe_comment_value(version)})"` if version
    present, else `"  - {safe_comment_value(name)}"`. Used by multiple renderers.

  `_brew_block(section: ParsedSection) -> str`
    Lines list:
    - 'echo "=== Homebrew Packages ==="'
    - A NOTE comment (literal # in the script): "# NOTE: A name that is both a formula and
      a cask may need explicit --formula or --cask; brew install auto-detects in most cases."
    - For each item: the universal guard
      `brew list {n} &>/dev/null || brew list --cask {n} &>/dev/null || brew install {n}`
      where `n = quote_for_script(item.name)`. Append `  # cataloged: {safe_comment_value(item.version)}`
      when item.version is not None.
    Returns "\n".join(lines).

  `_mas_block(section: ParsedSection) -> str`
    Split items into two lists: id-bearing (auto) and id-less (manual fallback).
    For auto items: `mas install {quote_for_script(item.id)}  # cataloged: {safe_comment_value(item.version)} — {safe_comment_value(item.name)}`
    (version part and name part omitted when version is None).
    For manual (id-less) items after the auto lines: emit
    `echo "App Store Applications (no ID — install manually):"` heading (only when there are
    id-less items), then `echo {shlex.quote(_checklist_display(item))}` per item.
    Returns "\n".join(lines).

  `_editor_ext_block(section: ParsedSection, *, editor: str) -> str`
    Lines list:
    - `echo "=== {section.title} ==="` (use section.title directly — it IS "VS Code Extensions"
      or "Cursor Extensions").
    For each item:
    - If item.id is None: `echo {shlex.quote(_checklist_display(item))}` (fallback, no install).
    - Otherwise: lowercase item.id first, then:
      `install_id = quote_for_script(low_id)`
      `grep_pat = quote_for_script("^" + low_id + "$")`
      `line = f"command -v {editor} >/dev/null && ! {editor} --list-extensions | grep -qi {grep_pat} && {editor} --install-extension {install_id}"`
      Append `  # cataloged: {safe_comment_value(item.version)}` when version present.
    Returns "\n".join(lines).

  `_manual_checklist_block(section: ParsedSection) -> str`
    `echo {shlex.quote(section.title + ":")}` as heading, then
    `echo {shlex.quote(_checklist_display(item))}` per item.
    Returns "\n".join(lines).

  Routing map (after all renderer functions, before public API — Python module-execution
  order constraint):
  `SECTION_SOURCE_MAP: dict[str, Callable[[ParsedSection], str]]`
  Four entries exactly:
    "Homebrew Packages"       → _brew_block
    "App Store Applications"  → _mas_block
    "VS Code Extensions"      → partial(_editor_ext_block, editor="code")
    "Cursor Extensions"       → partial(_editor_ext_block, editor="cursor")

  mypy --strict note (Assumption A1 from RESEARCH.md): if mypy --strict rejects
  `partial(_editor_ext_block, editor="code")` as `Callable[[ParsedSection], str]`, replace
  both partial() entries with lambdas:
    `"VS Code Extensions": lambda section: _editor_ext_block(section, editor="code")`
  This is equivalent at runtime and mypy-friendly.

  Public API (`emit_reinstall_script`):
  Signature: `def emit_reinstall_script(catalog: ParsedCatalog, *, source_name: str, generated: str) -> str`
  Docstring: full Args/Returns block — note zero-subprocess constraint, guaranteed bash -n
  pass, shlex.quote guarantee.
  Body:
  1. Build the header block:
       "#!/usr/bin/env bash\n"
       "set -Eeuo pipefail\n"
       "\n"
       f"# Generated from: {safe_comment_value(source_name)}\n"
       f"# Generated on:   {safe_comment_value(generated)}\n"
       "# Review this script before running — it is NOT auto-executed.\n"
  2. Iterate catalog.sections. For each section:
     - If _should_skip(section): continue.
     - renderer = SECTION_SOURCE_MAP.get(section.title) — if not None, call renderer(section)
       and append block.
     - If None (unknown title): append to a deferred manual_sections list.
  3. After the main loop, if manual_sections is non-empty:
     Emit a manual checklist preamble: 'echo ""' + 'echo "=== Manual Checklist ==="' +
     'echo "The following items require manual installation."'
     Then for each section in manual_sections: emit _manual_checklist_block(section).
  4. Join all blocks with "\n\n" and append a final "\n".
  Return the complete script string.
