<interfaces>
From src/maccat/helpers/chrome_name.py:
  chrome_ext_name(manifest_path: Path) -> str
  - manifest_path: Path to manifest.json inside the versioned extension dir
    (grandparent dir basename = ext_id)
  - Plain name in manifest → return name (or ext_id if empty)
  - name matches __MSG_<key>__ pattern → look up key (case-insensitive) in
    _locales/<default_locale>/messages.json
  - messages.json absent, key absent, or JSON malformed → return ext_id
  - messages[k] is a dict with "message" key → return messages[k]["message"]
  - first case-insensitive match wins

From src/maccat/helpers/vsc_name.py:
  resolve_vsc_ext_name(pkg_json: Path, ext_id: str) -> str
  - pkg_json: Path to package.json in the extension dir
  - No displayName → return ext_id
  - Plain displayName (no %...% wrapper) → return displayName
  - displayName matches %key% → look up key in package.nls.json (flat .get())
  - package.nls.json absent, key absent, JSON malformed → return ext_id
  - nls value not a plain string → return ext_id
</interfaces>
