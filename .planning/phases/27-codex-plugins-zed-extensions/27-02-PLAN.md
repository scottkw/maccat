```json

      "manifest": {"id": "html", "name": "HTML", "version": "0.3.1"},
      "dev": false
    }
  }
}
```
Access pattern: `data.get("extensions", {}).items()` — never `data["extensions"]`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-04 | Tampering | `ZedCollector` index.json parse | mitigate | Wrapped in `try/except (json.JSONDecodeError, OSError)`; returns empty section on any read failure; `data.get("extensions", {})` never raises KeyError |
| T-27-05 | Information Disclosure | Zed index.json content | accept | index.json contains extension id/name/version only — no tokens, keys, or credentials. Zed stores extension metadata in this file by design. Low risk. |
| T-27-06 | Denial of Service | Pathologically large index.json | accept | User's local filesystem; no untrusted source. Same risk profile as Firefox extensions.json (accepted in prior phases). |
| T-27-SC | Tampering | no new package installs in this plan | accept | stdlib-only; no npm/pip/cargo installs |
