| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-01 | Information Disclosure | render_markdown_catalog | mitigate | FMT-03 invariant: collectors never include MCP .command/.env/.args in item strings; markdown emitter is downstream and re-parses only the already-clean item strings — no new secret surface introduced. Belt-and-suspenders: TestDegradedSections verifies degradation lines never reach table rows. |
| T-30-02 | Tampering | YAML frontmatter (generated value) | mitigate | generated is double-quoted per Pattern 1 to prevent YAML 1.1 datetime auto-cast; fixed key order prevents key injection via f-string concatenation since all four values pass through controlled f-string slots |
| T-30-03 | Tampering | Table cell pipe injection | mitigate | _escape_cell replaces all literal "|" with "\|" before cell insertion; prevents a cell value from creating spurious columns |
| T-30-04 | Denial of Service | flush_section subprocess | accept | flush_section already in production use; non-zero sort exit raises RuntimeError and CatalogWriter discards the tmp file — no partial catalog committed. Scope of this plan is only the emitter module; no new subprocess surface. |
