<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cli.py generate loop → CatalogWriter | Content string passes through write_raw; atomic tmp+rename ensures no partial file |
| socket.gethostname() → frontmatter | Hostname value goes into YAML frontmatter — no YAML-unsafe characters in practice |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-08 | Tampering | CatalogWriter atomic write (FILE-02) | mitigate | write_raw writes the full pre-rendered string in one call inside the tmp+rename context manager; on exception the tmp is deleted and the .md file is never created at the final path — partial catalogs cannot be committed |
| T-30-09 | Information Disclosure | socket.gethostname() in frontmatter | accept | Hostname is machine identity already embedded in every catalog filename; no new disclosure surface beyond what .txt catalogs already contained |
| T-30-10 | Tampering | git add -A staging (FILE-02) | accept | gitops.git_commit_and_push uses "git add -A -- {computer}/" which is extension-agnostic; .md additions, archive moves, and deletions are all staged in one commit. No change needed per RESEARCH.md. |
| T-30-11 | Tampering | generated_iso timestamp (FMT-04 determinism) | mitigate | Both timestamp and generated_iso are derived from a single datetime.now() call; no second call that could produce a one-second drift. Tests inject a fixed timestamp to assert byte-identity. |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed — stdlib only. Package Legitimacy Gate not applicable. |
</threat_model>
