  Separator is exactly 36 ASCII dashes (SEPARATOR = "-" * 36).

  File may start with a leading blank line.
  Last section ends with "{last_item}\n" (no trailing blank line).

  @dataclass ParsedItem:
    name: str
    version: str | None
    id: str | None      # noqa: A003

  @dataclass ParsedSection:
    title: str
    items: list[ParsedItem] = field(default_factory=list)
    degraded: bool = False

  @dataclass ParsedCatalog:
    sections: list[ParsedSection] = field(default_factory=list)
    path: str = ""      # str not Path — serialization-friendly

Public API:
  parse_catalog(path: Path) -> ParsedCatalog

  NONE_FOUND_SENTINEL = "  (none found)"   # exactly two leading spaces
  DEGRADATION_LINES: frozenset[str] = frozenset({

  ITEM_RE = re.compile(...)   # right-anchored three-branch alternation (see RESEARCH.md)

State machine states (string literals or Enum — Claude's discretion):
  SEEKING_TITLE / SEEKING_SEPARATOR / COLLECTING

Regex named group naming (CRITICAL — Python re forbids duplicate names in alternation):
  Use "version" + "version2" and "id" + "id2" across branches.

    "version2"), id_ (group "id" or "id2"). Never raise.
  - Public function parse_catalog(path: Path) -> ParsedCatalog:
    Open with encoding="utf-8". Split on "\n". Three-state machine:
    SEEKING_TITLE / SEEKING_SEPARATOR / COLLECTING.
    State transitions (exact, per RESEARCH.md):
      SEEKING_TITLE + blank line -> stay SEEKING_TITLE
      SEEKING_TITLE + non-blank/non-separator -> current_title = line, go SEEKING_SEPARATOR
      SEEKING_SEPARATOR + 36-dash line -> go COLLECTING, reset items buffer
      SEEKING_SEPARATOR + blank -> stay SEEKING_SEPARATOR
      SEEKING_SEPARATOR + other -> discard current_title, go SEEKING_TITLE
      COLLECTING + blank -> flush section (title + items -> ParsedSection), go SEEKING_TITLE
      COLLECTING + non-blank -> handle the line per sentinel/degradation/item rules below
    Per-line handling in COLLECTING:
      if line == NONE_FOUND_SENTINEL: mark section as having zero items (degraded=False)
      elif line in DEGRADATION_LINES: mark section degraded=True (zero items)
      else: parse via _parse_item_line(line), append to current items buffer
    EOF flush: after the line loop, if state == COLLECTING and current_title is not None,
      flush the remaining buffer as the final ParsedSection (Pitfall 5 in RESEARCH.md).
    path argument: accept Path or str — coerce via Path(path) at function entry.
    Store str(path) in ParsedCatalog.path.
