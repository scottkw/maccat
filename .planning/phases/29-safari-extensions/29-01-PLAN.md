| plistlib → Info.plist on disk | Local filesystem reads of .appex bundles from /Applications and user-installed locations |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | Tampering | /usr/bin/pluginkit subprocess | accept | pluginkit is a macOS built-in (SIP-protected); no user-controlled arguments; argv is a constant |
| T-29-02 | Information Disclosure | Info.plist key reads | accept | reads only CFBundleDisplayName, CFBundleShortVersionString, CFBundleIdentifier — no secrets, no env vars, no credentials |
| T-29-03 | Denial of Service | per-extension plistlib.load | mitigate | each plist read individually wrapped in try/except Exception; one malformed plist cannot abort the run |
| T-29-04 | Spoofing | path from pluginkit output | accept | path is consumed read-only (plistlib.load) — no execution of cataloged paths; Path.open("rb") on a non-existent path raises, caught by per-extension except |
