    Append three new private/public definitions AFTER the existing parse_catalog function.

    1. Define module-level constant MD_NONE_FOUND = "(none found)" (no leading spaces —
       distinct from NONE_FOUND_SENTINEL which has two leading spaces for the legacy format).
       Place it with the other module-level constants (after DEGRADATION_LINES).

    2. Define _unescape_cell(value: str) -> str:
       Strip surrounding whitespace from value, then apply .replace("\\|", "|") followed
       by .replace("\\\\", "\\"). Return the result. Never raises.

    3. Define _parse_markdown_row(row: str) -> ParsedItem | None:
       Strip the leading "| " (2 chars) and trailing " |" (2 chars) via row[2:-2] to get
       inner. Split inner on " | " to get cols. If len(cols) != 3: name-only fallback —
       return ParsedItem(name=_unescape_cell(inner) or row, version=None, id=None, raw_line=row).
       Otherwise: name = _unescape_cell(cols[0]); version = _unescape_cell(cols[1]) or None;
       id_ = _unescape_cell(cols[2]) or None. If name is empty after unescaping, use row as
       the name (lenient at item level). Return ParsedItem(name=name, version=version, id=id_,
       raw_line=row). Never raises.

    4. Define parse_markdown_catalog(path: Path) -> ParsedCatalog:
       Docstring: state machine states (IN_FRONTMATTER, BODY), two ValueError cases.
       Body:
         a. path = Path(path) — accept both str and Path (mirrors parse_catalog pattern).
         b. Extension check: if path.suffix != ".md": raise ValueError(
              f"{path} is not a markdown catalog (.md extension required). "
              f"Convert it first with: maccat convert --from {path}"
            )
         c. text = path.read_text(encoding="utf-8") — propagates OSError to caller.
         d. lines = text.split("\n")
         e. Frontmatter validation: if not lines or lines[0] != "---": raise ValueError(
              f"{path} is missing valid YAML frontmatter (no opening '---' fence). "
              f"It may be a legacy .txt catalog renamed to .md. "
              f"Convert it first with: maccat convert --from {path}"
            )
         f. Find frontmatter closing fence: iterate lines[1:] with enumerate(start=1);
            first line equal to "---" is fm_close. If fm_close == -1 after the loop:
            raise ValueError(
              f"{path}: frontmatter block is not closed with '---'. "
              f"Convert it first with: maccat convert --from {path}"
            )
         g. catalog = ParsedCatalog(path=str(path))
            current_section: ParsedSection | None = None
         h. Iterate lines[fm_close + 1:]:
            - line.startswith("## "): flush current_section to catalog.sections if not None;
              set current_section = ParsedSection(title=line[3:])
            - line == MD_NONE_FOUND: no-op (items=[] and degraded=False already set)
            - line.startswith("| ") and line.endswith(" |"):
                if line in ("| Name | Version | ID |", "| --- | --- | --- |"): continue
                if current_section is not None:
                    item = _parse_markdown_row(line)
                    if item is not None: current_section.items.append(item)
            - all other lines (blank, H1 title, unrecognized): skip
         i. EOF flush: if current_section is not None: catalog.sections.append(current_section)
         j. return catalog

    - path = Path(path) as first statement

    - text.split("\n")
    - ParsedCatalog(path=str(path))

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem → parse_markdown_catalog | User-controlled catalog file content crosses into the parser; file may be hand-edited or externally modified |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Tampering | parse_markdown_catalog (table row parsing) | mitigate | Split on " | " not bare "|"; len(cols) != 3 falls back to name-only — no mis-parsed item can inject unexpected content into the reinstall script since emitter.py's quote_for_script() gate is downstream |
| T-31-02 | Denial of Service / ReDoS | parse_markdown_catalog (line iteration) | accept | No regex used in the markdown parser; all detection is string method calls (startswith, endswith, split, ==). No ReDoS surface. |
| T-31-03 | Information Disclosure | parse_markdown_catalog (ValueError messages) | accept | ValueError messages include the file path, which is user-supplied local data. No credentials or secrets are referenced; the message is shown only to the local user running maccat. |
| T-31-04 | Elevation of Privilege | reinstall pipeline (script execution) | accept | parse_markdown_catalog is purely I/O → dataclass. Nothing in this plan executes code. The reinstall.sh is written to disk and printed for manual review only (existing design, unchanged). |
| T-31-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase. stdlib-only. Package Legitimacy Gate does not apply. |
</threat_model>
