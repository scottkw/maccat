# Milestone v3.0.0 — Markdown Catalog Format — Audit

**Status: PASSED** — all 12 requirements satisfied, all 3 phases verified, all
cross-phase flows wired, no critical gaps, no accumulated tech debt.

## Definition of Done

A single `maccat` run produces a complete, restorable markdown (`.md`) snapshot of
a machine's software + tooling, the reinstall path consumes that markdown, and a
`convert` command upgrades legacy `.txt` catalogs in place — the round-trip contract
holding losslessly across emitter, reinstall parser, and convert.

## Cross-Phase Integration

All 3 end-to-end flows wired (integration checker, 702 tests passed):

1. **Generate → Reinstall** (30→31): `render_markdown_catalog` output parses cleanly via
   `parse_markdown_catalog`; lossless across all section/item shapes (9 round-trip tests).
2. **Convert → Reinstall** (32→31): a converted `.md` is consumable by `maccat reinstall`
   (round-trip + empty-section tests).
3. **Two-parser coexistence** (31+32): legacy `parse_catalog` (convert reads `.txt`) and
   new `parse_markdown_catalog` (reinstall reads `.md`) coexist without conflation; reinstall
   refuses `.txt`, convert refuses non-`.txt`.

0 orphaned exports, 0 missing connections, 0 broken flows.
