Verified: `command`, `env`, `args`, `url` value lines will not match the header regex |
| T-27-02 | Information Disclosure | `_collect_plugins` CLI path | mitigate | CAT-05: parse only `entry.get("name")` and `entry.get("pluginId")`; never emit `entry.get("command")` or `entry.get("env")`; same whitelist discipline as `_collect_via_cli` |
| T-27-03 | Information Disclosure | plugin bundle `.mcp.json` files | mitigate | Never read `.mcp.json` files — they can contain `env.API_KEY` credentials. FMT-03: identity-only from CLI output or TOML header lines exclusively |
| T-27-SC | Tampering | no new package installs in this plan | accept | stdlib-only; no npm/pip/cargo installs |
