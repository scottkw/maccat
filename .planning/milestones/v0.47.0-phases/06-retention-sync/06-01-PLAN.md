<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filename → retention logic | Catalog filenames are read from the local filesystem; they are attacker-controlled only if someone can write to the repo directory |
| retain_newest_per_host → archive/ | mv moves files out of main; a bug here causes irreversible data movement (not deletion, but loss of the main-folder copy) |
| prune_old_archives → rm | rm permanently destroys files; a bug in file selection or the date comparison causes irreversible data loss |
| git add -A scope | git add -A scoped to TARGET_LOCATION/; a broader path (e.g., the repo root) would stage unrelated files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
