| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | new_label user input → OUTPUT_FILENAME / TSV write | mitigate | validate_machine_label reused verbatim — rejects /, [, ], TAB, newline, leading/trailing whitespace; empty check enforced before any write |
| T-09-02 | Tampering | new_label → mv destination path | mitigate | new_filename constructed from validated new_label + extracted 14-digit timestamp only; no eval, no command substitution from user input |
| T-09-03 | Tampering | machine-labels.tsv atomic rewrite | mitigate | .tmp + mv pattern (same as upsert_machine_label) prevents partial-write corruption; comments/blanks preserved verbatim, never interpreted |
| T-09-04 | Denial of Service | destination collision overwrites existing catalog | mitigate | explicit [[ -e "$dest" ]] check before mv; skip + warn on collision, never overwrite; renamed_count and skipped_count reported to user |
| T-09-05 | Information Disclosure | label values logged to stdout | accept | labels are user-chosen friendly strings, not secrets; stdout logging consistent with all existing echo patterns in the script |
| T-09-SC | Tampering | npm/pip/cargo package installs | accept | no package manager installs in this phase; pure Zsh with no new dependencies |
