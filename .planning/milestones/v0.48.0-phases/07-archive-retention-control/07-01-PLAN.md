## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | parse_arguments --archive-days | mitigate | Validate with `^[0-9]+$` regex and `(( val >= 1 ))` before assigning to ARCHIVE_AGE_DAYS; reject and exit 1 on failure |
| T-07-02 | Tampering | resolve_archive_retention prompt input | mitigate | Same validation idiom applied to prompt-read value before overwriting ARCHIVE_AGE_DAYS |
| T-07-03 | Denial of Service | resolve_archive_retention read hang | mitigate | `[[ -t 0 ]]` TTY check before issuing read; non-TTY path skips read entirely and uses default 30 |
| T-07-04 | Elevation of Privilege | large --archive-days value deleting recent files | accept | No upper bound is intentional per CONTEXT.md; user explicitly chose the value; no PII or high-value target |
</threat_model>
