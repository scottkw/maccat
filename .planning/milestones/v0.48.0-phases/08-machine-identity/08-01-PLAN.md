<objective>
Implement machine identity: replace the raw `$(hostname)` value in the catalog filename's
`[...]` segment with a user-chosen friendly label. Label is resolved from the `--machine`
flag, a committed hostname→label map (`machine-labels.tsv`), or an interactive numbered
menu (with "create new"). Each machine is prompted once; subsequent runs auto-resolve.

Purpose: Users get human-readable, consistent filenames across machines (e.g. `[Example Computer
Air]` instead of `[computer-one.local]`); the map is committed so all machines
converge on pull.

Output:
- `update-list.sh` — extended with `--machine` flag, `resolve_machine_label` function, and
  rewired `OUTPUT_FILENAME`/`git_commit_and_push`
- `machine-labels.tsv` — new committed map file at repo root (can be empty initially)
</objective>
