# Requirements: Mac Software List Generator

**Defined:** 2026-06-13
**Milestone:** v0.48.0 Machine Identity & Retention Control
**Core Value:** A single run produces one complete, restorable snapshot of a machine's software *and* tooling extensions — accurate enough to rebuild the environment from, degrading gracefully when any source isn't installed.

## v1 Requirements

Requirements for milestone v0.48.0. Each maps to a roadmap phase.

### Archive Retention (ARC)

- [x] **ARC-01**: User can set the archive-retention period for a run by passing `--archive-days N` (overrides the default of 30)
- [x] **ARC-02**: When `--archive-days` is not provided, the script prompts for the retention period, defaulting to 30
- [x] **ARC-03**: An invalid `--archive-days` value (non-numeric or ≤ 0) is rejected with an error before any archive pruning runs

### Machine Identity (MID)

- [x] **MID-01**: Catalog files are named with the machine's friendly label in the `[...]` filename segment instead of the raw hostname
- [x] **MID-02**: When no label is resolved for the run, the script presents a menu of existing machine labels plus a "create new" option
- [x] **MID-03**: User can pass `--machine "Label"` to set the run's machine label without being prompted
- [x] **MID-04**: The script persists a committed hostname→label map and auto-uses this Mac's label on subsequent runs (prompting only the first time a machine is seen)

### Machine Rename (REN)

- [x] **REN-01**: User can rename a machine label, rewriting it across every one of that machine's catalog files in both locations (`personal/` + `office/`, main folder + `archive/`)
- [x] **REN-02**: A rename updates the hostname→label map and stages all renames in a single git commit/push so other machines converge on pull

## v2 Requirements

Deferred to future releases. Tracked but not in the current roadmap.

### Reinstall (RST)

- **RST-01**: Generate a reviewable `reinstall.sh` from a chosen catalog that reinstalls deterministic sources (Homebrew formulae/casks, Mac App Store apps, VS Code/Cursor extensions)
- **RST-02**: The generated script lists non-deterministic sources (Setapp, web-installed apps, browser/AI-CLI extensions, MCP servers) as a manual checklist rather than attempting to install them
- **RST-03**: The generated script is emitted for user review and is never auto-executed

### Deferred from prior milestones

- **CHR-02 / FF-02**: Capture browser-extension enabled/disabled state
- **CDX-02**: Catalog Codex plugins once that subsystem ships

## Out of Scope

Explicitly excluded for v0.48.0. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Reinstall / restore from a catalog | The planned **next** milestone; this milestone only adds identity + retention controls |
| Persisted config file for retention | User chose a flag-or-prompt model (`--archive-days N`, else prompt); no config file this milestone |
| Catalog diffing / change reports | Valuable but a separate milestone |
| Cross-platform support (Linux/Windows) | Tool is macOS/Zsh-only by design (BSD `date -v`, `/Applications`, browser paths) |
| JSON/HTML output formats | Output stays plain-text sectioned to keep one restorable snapshot |
| Browsers/editors beyond those already covered | Not requested |
| Rewriting the script's architecture (globals-as-parameters, etc.) | Bolt new behavior onto existing conventions rather than refactor |
