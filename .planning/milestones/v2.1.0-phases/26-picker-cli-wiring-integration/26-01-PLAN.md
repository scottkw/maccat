<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied --from PATH | User provides a filesystem path to their own catalog file; the tool reads it and generates a script in cwd |
| catalog-derived values → script content | Catalog item strings (names, versions, IDs) flow from parse_catalog into emit_reinstall_script |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Tampering | --from PATH user input | accept | Path is resolved via Path.expanduser().resolve(); error if not a regular file. User runs this tool against their own catalogs — no privilege boundary crossed. Path traversal is the user's own filesystem. |
