write_section "$title"
  — writes a separator + titled header to OUTPUT_FILE; initializes a new section.

json_get "$file" "$dotted_key"
  — returns scalar via jq (primary), plutil (fallback), or "" on miss.
  — For nested keys, use dot notation: "mcpServers.execbro.type"

emit_item "$name" "$version" "$id"
  — writes uniform "name (version) [id]" line into _section_lines buffer.
  — Pass "" for missing fields; FMT-01 degrades gracefully.
  — MCP convention: emit_item "$name" "" "$transport" → "name [transport]"

flush_section
  — LC_ALL=C sort -f -u on _section_lines, writes to OUTPUT_FILE.

  — Resets _section_lines=(). MUST be called at end of every collector.

_section_lines=()
  — global buffer array; reset at start of EVERY collector (defensive against

| ~/.claude.json → collector | Local config file read by script; contains secret-bearing fields (env, command, args) alongside the safe type field |
| ~/.claude/plugins/installed_plugins.json → collector | Local JSON with version info; no secrets, but plutil xml1 output parsing must extract keys only |
| ~/.claude/skills/ + ~/.claude/agents/ → collector | Local filesystem dirs; SKILL.md/agent .md files contain names only — no credential fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | collect_claude_mcp — reads ~/.claude.json | mitigate | jq expression reads ONLY `.key` and `.value.type`; plutil path reads only `mcpServers` (key names) and `mcpServers.${name}.type` scalar; NEVER reads `.value.env`, `.value.command`, `.value.args`, `.value.url`, `.value.headers`; transport label clamped to stdio/http/sse whitelist |
| T-03-02 | Information Disclosure | transport label injection via adversarial type field | mitigate | case statement clamps transport to `stdio\|http\|sse`; any other value replaced with "stdio" before emit_item — prevents arbitrary string injection via a crafted config |
| T-03-03 | Tampering | installed_plugins.json corruption or absent | accept | Absent file → flush_section writes "(none found)"; malformed JSON → jq exits non-zero, loop receives no output → flush_section writes "(none found)"; no abort |
| T-03-SC | Tampering | npm/pip/cargo package installs | accept | Phase 3 installs no packages; this threat is not applicable |
