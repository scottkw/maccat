    ## resolve_computer_selection(*, computer: str | None, personal: bool, office: bool, machine: str | None) -> str | None
    Zsh analog: update-list.sh lines 199–268 (the flag-alias cases and the post-loop mutual-exclusion guard). This is the pure resolution function that Phase 16's argparse dispatch will call; it holds NO argparse and needs NO TTY.

    Selecting-flag count: count how many of the four inputs are "set":
    - personal is True (maps to "personal" — zsh line 200)
    - office is True (maps to "office" — zsh line 205)
    - machine is a non-None/non-empty string (maps to machine — zsh line 247, the silent back-compat alias)
    - computer is a non-None/non-empty string (maps to computer — zsh line 216)

    Rules (exactly mirroring zsh):
    - More than one set → raise SystemExit("ERROR: --personal, --office, --computer, and --machine are mutually exclusive.") (zsh lines 265–267). This message is the actionable mutual-exclusion error.
    - Exactly one set → resolve to its mapped value:
        personal → "personal"
        office   → "office"
        machine  → the machine string, AFTER validate_computer_name(machine) (zsh line 246 validates before assigning)
        computer → the computer string, AFTER validate_computer_name(computer) (zsh line 215 validates before assigning)
    - Zero set → return None. None means "no flag given — caller falls back to the interactive menu" (select_computer with computer_name=None).

    NOTE: validate_computer_name raises SystemExit on an invalid name (same as the zsh `validate_computer_name` call inside the --computer/--machine cases). For --personal/--office the value is a fixed literal and is NOT re-validated (matches zsh — those cases never call validate_computer_name).

    NOTE: This function does NOT implement the --rename × selecting-flag combination guard (zsh lines 270–277). That guard depends on RENAME_MODE parser state and belongs to Phase 16's argparse dispatch.

    ## validate_computer_name(val: str) -> None
    Raises SystemExit on: empty string, leading/trailing whitespace, contains /[]\ (slash, open-bracket, close-bracket), contains \t or \n. No exception for valid names.

    ## validate_computer_name_quiet(val: str) -> str | None
    Same rules but returns error message string (not raise) for invalid, None for valid. Used in re-prompt loops.

    ## discover_computer_folders(catalog_repo: Path) -> list[str]
    Returns alphabetically sorted union of: (a) top-level dirs in catalog_repo that contain at least one mac-software-list-*.txt file, (b) machine column 2 values from machine-labels.tsv (skipping # lines, blank lines, lines without tab). Deduplication via seen set. No promotion/default logic here.

    ## select_computer(catalog_repo: Path, *, computer_name: str | None = None) -> str | None
    Flag path (computer_name is non-None — the value resolved by resolve_computer_selection): mkdir -p the folder, upsert_machine_label, print "Computer: {name} (from command-line argument)", return name.

    Non-TTY guard (when computer_name is None): if not sys.stdin.isatty() → raise SystemExit('ERROR: No computer selected and stdin is not a TTY. Pass --computer "Name".')

    TSV lookup for saved_folder: read machine-labels.tsv, find row matching socket.gethostname(), store as saved_folder (or "" if not found/file absent).

    Folder discovery: call discover_computer_folders(catalog_repo). If saved_folder in computers, promote it to position 0 (insert at front, remove from original position).

    Menu display (exact strings from PATTERNS.md):
    - Print blank line, "Select a computer:", blank line
    - For each folder: "  {i}) {name}" or "  {i}) {name}   (this machine — default)" (3 spaces before paren) when folder == saved_folder
    - "  {create_new_idx}) Create new computer"
    - "  {quit_idx}) Quit"
    - Print blank line

    Input loop: prompt "Enter your choice [1-{quit_idx}, or Enter for the default]: " (when saved_folder set) or "Enter your choice [1-{quit_idx}]: " (when not). EOF → clean return of None (never continue). q/quit → quit_idx. Empty input when saved_folder set → resolve to saved_folder's index (if saved_folder not in computers → raise SystemExit("ERROR: saved default '{saved_folder}' is not in the computer list.")). Empty input when no saved_folder → re-prompt "No default for this machine — please enter a number.". Invalid → re-prompt "ERROR: Invalid choice '{choice}'. Please enter 1-{quit_idx}.".

    Quit branch: print "No catalog written." return None. Create-new branch: prompt "Enter a name for the new computer: ", EOF → print "No catalog written." return None, validate with validate_computer_name_quiet → re-prompt on error. After selecting: mkdir_p(catalog_repo / name), upsert_machine_label, print "Computer: {name}", return name.

    ## upsert_machine_label(catalog_repo: Path, folder: str) -> None
    map_file = catalog_repo / "machine-labels.tsv". Create with 3-line header if absent (exact header text from RESEARCH.md §4). Atomic rewrite: build out list preserving blank lines and comments; replace existing host entry if found, append if not found. `tempfile.mkstemp(dir=catalog_repo, suffix=".tmp")` + `os.fdopen(fd, "w", encoding="utf-8", newline="\n")` + `Path(tmp).rename(map_file)`. Print "  Saved computer folder mapping: {hostname} -> {folder}".

    ## rename_machine(catalog_repo: Path, *, auto_commit: bool = False) -> None
    TTY guard: if not sys.stdin.isatty() → raise SystemExit("ERROR: --rename requires an interactive terminal (stdin is not a TTY). Cannot prompt for computer names.").

    Discovery: discover_computer_folders (no saved-default promotion). If empty → print "No computers found. Nothing to rename." return.

    Rename picker menu (NO Create new computer option, NO Enter-default):
    - "Select the computer to rename:", numbered list, "  {quit_idx}) Quit"
    - EOF / q / quit → print "Nothing renamed." return

    New name prompt: "Enter new name for '{old_name}': ". EOF → print "Nothing renamed." return. validate_computer_name_quiet → re-prompt on error.

    Guards (in order):
    1. new == old → print "WARNING: New name is the same as the old name ('{old_name}'). Nothing renamed." return
    2. old_dir = catalog_repo / old_name; if not old_dir.is_dir() → print "WARNING: Computer folder '{old_name}' not found in {catalog_repo}. Nothing renamed." return
    3. new_dir = catalog_repo / new_name; if new_dir.exists() → raise SystemExit("ERROR: A computer named '{new_name}' already exists. Refusing to merge. Nothing renamed.")

    Folder move: old_dir.rename(new_dir). Print "  Renamed folder: {old_name}/ -> {new_name}/". (archive/ subfolder moves with parent — single rename operation.)

    Opt-out filename rewrite prompt: "Rewrite all existing catalogs in '{new_name}' to '[{new_name}]'? [Y/n]: ". EOF = accept default (yes). Empty / y / yes → rewrite. n / no → skip. Rewrite scope: new_dir/ AND new_dir/archive/. Per-file: parse via parse_catalog_filename; skip if None or label != old_name. Construct new filename via make_catalog_filename(new_name, cf.timestamp). Collision guard: if new_dir/new_filename exists → warn and skip (never overwrite). Rename file.

    TSV map update (unconditional — runs regardless of rewrite choice): read machine-labels.tsv; rewrite lines where second column equals old_name exactly, replace with new_name. Atomic write same pattern as upsert_machine_label.

    Git stub: `# Phase 16: if auto_commit: git_commit(catalog_repo, ...)` — comment only, no implementation.

    Return None.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| computer_name (--computer / --machine flag value) | user-supplied string; validate before any filesystem use |
| selecting-flag combination | more than one selecting flag is ambiguous; must fail fast before any folder is created |
| machine-labels.tsv | file at catalog_repo root; read/written by tool; must never corrupt on crash |
| catalog folder names from filesystem | adversarially-named dirs could contain path traversal chars |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-06 | Tampering | validate_computer_name | mitigate | Rejects / (path traversal), [ and ] (corrupt [label] split in filenames), leading/trailing whitespace, tab (TSV corruption), newline (TSV multi-line corruption) — four rules exactly matching update-list.sh lines 117–175 |
| T-14-06b | Tampering | resolve_computer_selection mutual-exclusion | mitigate | More-than-one selecting flag → SystemExit before any folder/TSV mutation (mirrors update-list.sh lines 263–268); resolved --computer/--machine values pass through validate_computer_name before return |

| T-14-09 | Denial of Service | select_computer non-TTY hang | mitigate | sys.stdin.isatty() check BEFORE any input() call; non-TTY → immediate SystemExit; EOF → return None (never continue in except) |
