    ## _default_config_path() -> Path
    Reads XDG_CONFIG_HOME env var; if set uses Path(xdg_val) as base, else uses Path.home() / ".config". Returns base / "maccat" / "config.toml". NEVER uses platformdirs. NEVER uses Path(__file__).parent or os.getcwd().

    ## Config dataclass
    @dataclass with field catalog_dir: Path | None = None.

    ## load_config(config_path: Path | None = None) -> Config
    Uses config_path if provided, else calls _default_config_path(). If file absent: return Config(). Open "rb" (REQUIRED by tomllib), call tomllib.load(f), get raw.get("catalog_dir"), return Config(catalog_dir=Path(raw_dir).expanduser() if raw_dir else None).

    ## resolve_catalog_repo(flag_val: str | None, config: Config) -> Path
    Precedence (CFG-01, locked):
    1. flag_val (--catalog-dir): if truthy → Path(flag_val).expanduser().resolve(). NEVER writes to config.
    2. MACCAT_CATALOG_DIR env: os.environ.get("MACCAT_CATALOG_DIR") if truthy → Path(env_val).expanduser().resolve()
    3. config.catalog_dir if truthy → config.catalog_dir.expanduser().resolve()
    4. All absent → raise SystemExit with actionable multi-line error listing all three options

    ## validate_catalog_repo(catalog_repo: Path) -> None
    If not catalog_repo.is_dir() → raise SystemExit("ERROR: Catalog directory not found: {catalog_repo}\nRun `maccat config init` to configure a valid catalog repo.").
    Run subprocess.run(["git", "rev-parse", "--git-dir"], cwd=catalog_repo, capture_output=True); if returncode != 0 → raise SystemExit("ERROR: {catalog_repo} is not a git repository.\nRun `maccat config init` to configure a valid catalog repo.").
    Run subprocess.run(["git", "remote"], cwd=catalog_repo, capture_output=True, text=True); if returncode != 0 or not stdout.strip() → print("  WARNING: No git remote configured in {catalog_repo}. Changes will not be pushed.") and return (warn-and-continue, not fatal — CFG-06).

    ## _toml_string(s: str) -> str
    Escapes for TOML basic string: s.replace("\\", "\\\\").replace('"', '\\"'). Returns '"' + escaped + '"'.

    ## write_config(config_path: Path, catalog_dir: Path) -> None
    config_path.parent.mkdir(parents=True, exist_ok=True). content = f"catalog_dir = {_toml_string(str(catalog_dir))}\n". Atomic write: tempfile.mkstemp(dir=config_path.parent, suffix=".tmp") + os.fdopen + f.write(content) + Path(tmp).rename(config_path).

    ## config_init(config_path: Path | None = None) -> None
    TTY guard: if not sys.stdin.isatty() → raise SystemExit("ERROR: `maccat config init` requires an interactive terminal.").
    Display: print(f"Config file: {path}"). Interactive loop: prompt "Enter the path to your catalog repository: ". EOF → raise SystemExit("\nAborted."). Expand/resolve the path. Validate: is_dir check, then is_git_repo check (re-prompt with actionable error on failure). On valid: call write_config; print f"Config written to: {path}"; break.

    ## config_show(flag_val: str | None, config: Config, config_path: Path | None = None) -> None
    Determine source and value using same precedence logic as resolve_catalog_repo but WITHOUT raising — just detect which source provides a value.
    Print:
      "Catalog repo: {value}   [from: --catalog-dir flag]"   (if flag_val)
      "Catalog repo: {value}   [from: MACCAT_CATALOG_DIR env var]"   (if env)
      "Catalog repo: {value}   [from: config file]"   (if config.catalog_dir)
      "Catalog repo: (not configured)"   (if none)
    Always print: "Config file:  {path}"
    If not configured: also print "  Run `maccat config init` to configure."

    ## resolve_archive_days(flag_val: int | None, *, default: int = 30) -> int
    Zsh analog: update-list.sh lines 511–541 (resolve_archive_retention).
    If flag_val is not None: print f"Archive retention: {flag_val} days"; return flag_val.
    If not sys.stdin.isatty(): print f"Archive retention: {default} days (non-interactive, using default)"; return default.
    Interactive: prompt "Archive retention period in days [{default}]: ". Empty input → return default. Non-empty → validate int >= 1 (raise SystemExit on invalid). Return validated int.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| --catalog-dir flag value | user-supplied filesystem path; expand+resolve before use |
| MACCAT_CATALOG_DIR env var | user/environment-supplied path; same treatment |
| config.toml content | file on local disk; parsed by tomllib; malformed TOML raises exception |
| config_init user input | interactive path prompt; validate exists + is git repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-11 | Tampering | resolve_catalog_repo path | mitigate | Path(val).expanduser().resolve() normalizes path traversal sequences (../../etc) to absolute canonical paths; validate_catalog_repo then checks existence and git-repo identity before any catalog operation |
| T-14-12 | Tampering | write_config TOML injection | mitigate | _toml_string escapes \ and " in path values per TOML spec; tomllib parses the result correctly; macOS paths rarely contain these but code is correct |
| T-14-13 | Tampering | write_config atomic write | mitigate | tempfile.mkstemp + Path.rename; crash leaves .tmp at most; config.toml never partially written |
| T-14-14 | Information Disclosure | config.toml world-readable | accept | Contains only catalog repo path (no secrets); default umask 0o644 on macOS is acceptable for a personal tool |
| T-14-15 | Tampering | subprocess git commands in validate_catalog_repo | mitigate | list form, shell=False (default); cwd=catalog_repo (no path expansion via shell); capture_output=True suppresses leaking to user terminal |
| T-14-16 | Denial of Service | config_init non-TTY hang | mitigate | sys.stdin.isatty() guard at function entry; non-TTY raises SystemExit immediately before any input() call |
| T-14-SC | Tampering | npm/pip/cargo installs | accept | Phase 14 is stdlib-only; no package installs in this plan |
