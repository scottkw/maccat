    ## retain_newest_per_host(target_dir: Path) -> None

    Zsh analog: update-list.sh lines 942–1004 (retain_newest_per_host).

    Pass 1 (lines 957–973): Glob `mac-software-list-*.txt` in target_dir (main folder only — NOT archive/). For each file, call parse_catalog_filename. If None: print warning "  WARNING: Could not parse hostname/timestamp from: {name}" and continue. Track newest timestamp per machine key in a dict[str, str].

    Pass 2 (lines 976–996): Glob again. If parse returns None: continue silently (already warned). If cf.timestamp == newest[cf.machine]: continue (KEEP — this handles tied-newest correctly because both tied files share the same max timestamp). Otherwise: rename file to archive_dir / f.name; on OSError print warning.

    Creates archive_dir with mkdir(exist_ok=True) at the start.

    Test cases:
    - test_single_file_stays_in_main: one file → still in target_dir after call
    - test_older_file_moved_to_archive: two files same host, timestamps T1 < T2 → T1 in archive, T2 in main
    - test_tied_newest_both_kept: two files same host, same timestamp → BOTH in main, archive empty
    - test_unparseable_filename_never_moved: non-catalog .txt → still in target_dir (not in archive)
    - test_non_catalog_txt_untouched: README.txt in target_dir → untouched
    - test_archive_dir_created_if_absent: target_dir with no archive/ → archive/ created after call
    - test_multiple_hosts_independent: two hosts each with old+new → each host's old file archived, new kept

    ## prune_old_archives(archive_dir: Path, archive_days: int) -> None

    Zsh analog: update-list.sh lines 1022–1064 (prune_old_archives).

    Early return if archive_dir does not exist (prints "  No archive directory found — nothing to prune.").

    Cutoff: `cutoff_yyyymmdd(archive_days)` = `(datetime.now() - timedelta(days=archive_days)).strftime("%Y%m%d")`. Uses local time, matching BSD `date -v-Nd +%Y%m%d`.

    For each mac-software-list-*.txt in archive_dir: parse via parse_catalog_filename. If None: print "  WARNING: Could not parse timestamp from: {name} — skipping" and continue — NEVER delete. Extract first 8 chars of timestamp (YYYYMMDD). String comparison: if file_yyyymmdd < cutoff → unlink + print "  Pruned: {name}". String < is correct because YYYYMMDD is lexicographically ordered.

    Test cases:
    - test_old_file_deleted: file with YYYYMMDD before cutoff → deleted
    - test_recent_file_kept: file with YYYYMMDD after cutoff → still present
    - test_boundary_date_kept: file with YYYYMMDD == cutoff → kept (not deleted; < not <=)
    - test_unparseable_filename_never_deleted: non-matching .txt → still present after call
    - test_missing_archive_dir_no_error: no archive/ directory → returns cleanly, no exception

    ## cutoff_yyyymmdd(archive_days: int) -> str
    Returns (datetime.now() - timedelta(days=archive_days)).strftime("%Y%m%d").

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-03 | Tampering | retain_newest_per_host | mitigate | parse_catalog_filename guards: unparseable filename → skip with warning, never move; two-pass algorithm is deterministic and only archives files that are strictly non-newest |
| T-14-04 | Tampering | prune_old_archives | mitigate | parse_catalog_filename guards: unparseable → skip, never delete; only files passing parse AND having timestamp < cutoff are deleted; operates on archive/ only — never on the main computer folder |
