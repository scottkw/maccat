    Define `_FILENAME_RE = re.compile(r"^mac-software-list-\[(?P<machine>[^\[\]]+)\]-(?P<ts>\d{14})\.txt$")` — this regex is derived from the zsh parameter expansion at update-list.sh lines 964–965 and 982–983, and the grep-oE pattern at those same lines. The `[^\[\]]+` group prevents brackets inside the machine label, matching the validation rule in validate_computer_name.

    Define `@dataclass(frozen=True) class CatalogFilename` with fields: `machine: str`, `timestamp: str`, `filename: str`. Add a one-line class docstring.

    Define `parse_catalog_filename(filename: str) -> CatalogFilename | None` — returns None (never raises) for non-matching names, mirrors the zsh warn-and-continue policy. Match against `_FILENAME_RE`, return None if no match, otherwise return CatalogFilename with named groups.

    Define `make_catalog_filename(machine: str, timestamp: str) -> str` — returns `f"mac-software-list-[{machine}]-{timestamp}.txt"`. No validation here; validation belongs in validate_computer_name (caller's responsibility per PATTERNS.md).

Use `from maccat.naming import CatalogFilename, make_catalog_filename, parse_catalog_filename`. Cover: valid filename round-trip, spaces in machine name, non-matching names return None (not raise), brackets in machine label return None, 13-digit ts returns None, 15-digit ts returns None, .gitkeep returns None, make output format assertion.
