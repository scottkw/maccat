  <action>
  Create `src/maccat/__main__.py` with this exact structure (per PKG-02):

  1. First executable code: `import sys` (the ONLY top-level import)
  2. Version guard: `if sys.version_info < (3, 11): sys.exit(...)` with a multi-line actionable
     message that includes the Python version found, Homebrew install command
     (`brew install python@3.11`), direct download URL (`https://python.org/downloads/`), and
     a note that `/usr/bin/python3 on macOS is Python 3.9 (EOL)`. Use `sys.exit(str)` — not
     `print()` + `sys.exit(1)` separately.
  3. After the guard: define `main() -> None:` with a deferred import `from maccat.cli import run`
     inside the function body (Phase 16 will implement `cli.run`; the stub body just does `pass`
     or raises `NotImplementedError("Phase 16")` — either is acceptable).
  4. Standard `if __name__ == "__main__": main()` guard at the bottom.

  CRITICAL: No `from maccat.*` imports at module top level. All package imports must be
  deferred into `main()` or helper functions so the version check fires first on sub-3.11
  interpreters that would fail on union type syntax (`X | Y`) in other modules.

  Then create the dev venv and install dev dependencies (per CLAUDE.md: always use venv, never install globally):
  - `python3 -m venv venv`
  - `./venv/bin/pip install -e ".[dev]"` (installs pytest, ruff, mypy, plus the package itself in editable mode)

  The venv is not committed to git — verify `.gitignore` already excludes `venv/` (or add it if missing). Do NOT add `venv/` to git.
  </action>
