<objective>
Implement the three name-resolution helpers — `json_io.py` (dotted-path JSON extractor),
`chrome_name.py` (Chrome `__MSG_…__` placeholder resolver), and `vsc_name.py` (VS Code
`%nls%` flat-key resolver) — plus the `tests/conftest.py` fixture factory, `test_helpers.py`
unit tests, and the `tests/golden/` directory scaffold for Phase 17.

Purpose: CAT-04 requires that Chrome and VS Code extension display names are resolved using
exactly the same fallback logic as the zsh reference. These helpers are also used by Phase 15
collectors for every extension enumeration. The `json_get` helper replaces the jq+plutil
subprocess chain entirely with `json.loads()` — faster and more reliable.

Output:
- `src/maccat/helpers/json_io.py` — `json_get(file, key, default="") -> str`
- `src/maccat/helpers/chrome_name.py` — `chrome_ext_name(manifest_path) -> str`
- `src/maccat/helpers/vsc_name.py` — `resolve_vsc_ext_name(pkg_json, ext_id) -> str`
- `tests/conftest.py` — `tmp_json` fixture factory
- `tests/test_helpers.py` — unit tests for all three helpers
- `tests/golden/.gitkeep` — directory scaffold for Phase 17 golden fixtures
</objective>

  - Module header: `from __future__ import annotations`, `import json`, `from pathlib import Path`,
    `from maccat.helpers.json_io import json_get`
  - `ext_id = manifest_path.parent.parent.name` — grandparent dir (ext ID, not version dir)
  - `name = json_get(manifest_path, "name")`
  - Non-placeholder check: `if not (name.startswith("__MSG_") and name.endswith("__") and len(name) > len("__MSG__"))` → return `name if name else ext_id`
  - Extract key: `msg_key = name[len("__MSG_"):-len("__")]`
  - Locale: `locale = json_get(manifest_path, "default_locale") or "en"`
  - messages_file path: `manifest_path.parent / "_locales" / locale / "messages.json"`
  - If not exists → return `ext_id`
  - Load messages, catch `(json.JSONDecodeError, OSError)` → return `ext_id`
  - Case-insensitive lookup: `lowered = {k.lower(): v for k, v in messages.items()}`; `entry = lowered.get(msg_key.lower())`
  - If `entry` is a dict: `resolved = entry.get("message", "")` → return if truthy
  - Fallback: return `ext_id`

  - FLAT lookup: `resolved = nls.get(nls_key, "")` — NEVER use `json_get(nls_file, nls_key)` here
  - Return `resolved if resolved else ext_id`
