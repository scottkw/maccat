<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| flush_section → subprocess stdin | Item names from extension manifests pass through stdin to sort binary |
| CatalogWriter → filesystem | Writes to catalog repo dir passed by caller; path must point to a valid writable directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-03 | Tampering | `subprocess.run(["sort", "-f", "-u"], input=...)` | mitigate | Command as list (not string) — no shell injection possible even if item names contain shell metacharacters. `shell=False` is the default and must never be overridden. |
| T-13-04 | Tampering | `CatalogWriter` tmp file | mitigate | `tempfile.mkstemp` creates the tmp file with mode 0600; rename is atomic on POSIX (macOS). No other process can observe a partial write. |
| T-13-05 | Information Disclosure | CatalogWriter encoding | accept | Output file is `encoding="utf-8"`, `newline="\n"` — no binary secrets encoded; catalog content is software names only at this layer (secret suppression is CAT-05, Phase 15). |
  T-13-SC | Tampering | npm/pip/cargo installs | accept | No new installs in Plan 02. Dev venv installed in Plan 01. |
</threat_model>
