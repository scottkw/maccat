      12. txt_path.unlink()  — ONLY after step 11 succeeds (CONV-03 invariant)
      13. print(f"Converted: {txt_path.name} -> {md_path.name}")

              from maccat import gitops

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → run_convert | --from PATH is user-controlled; the path is normalised and validated before use |
| File system → .md write | Output path is derived deterministically from input path (with_suffix), never from user-supplied data beyond the validated filename |
| .txt content → parse_catalog | Legacy catalog content is parsed (never executed); parse_catalog produces typed dataclasses only |
| convert.py → gitops | git args are list-form (no shell interpolation); cwd is the validated catalog_repo path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-01 | Tampering | run_convert: output path derivation | mitigate | Output path is `txt_path.with_suffix(".md")` — cannot escape txt_path.parent; derived from input, never from user string injection |
| T-32-02 | Tampering | run_convert: clobber existing .md | mitigate | No-clobber guard (USER OVERRIDE): `if md_path.exists(): sys.exit(ERROR)` before any write |
| T-32-03 | Tampering | run_convert: atomicity (data loss) | mitigate | txt_path.unlink() called ONLY after md_path.write_text() returns without exception |
| T-32-04 | Information Disclosure | run_convert: arbitrary file read via --from | mitigate | is_file() + os.access(R_OK) before open; file content is never echoed to stdout; emitter enforces FMT-03 identity-only for MCP/AI-CLI entries |
| T-32-05 | Tampering | git_commit_convert: shell injection via file paths | mitigate | subprocess args are list-form (shell=False); paths passed as str(rel_path) positional elements, never interpolated into a shell string |
| T-32-06 | Elevation of Privilege | run_convert: executing parsed content | accept | parse_catalog produces typed dataclasses; nothing in the pipeline calls subprocess, eval, or exec with user content |
| T-32-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase; stdlib-only |
</threat_model>
