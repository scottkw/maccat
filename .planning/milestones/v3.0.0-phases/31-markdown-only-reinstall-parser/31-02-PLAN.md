<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied --from PATH → run_reinstall | Caller provides path to a local file; path resolution and read are already guarded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-05 | Spoofing / Tampering | cli.py ValueError catch | mitigate | ValueError from parse_markdown_catalog contains the actionable convert message; sys.exit converts it cleanly with "ERROR:" prefix — no raw traceback escapes to the user |
| T-31-06 | Information Disclosure | sys.exit error message | accept | Error message contains the file path (user-supplied, local). No credentials. Message is shown only to the local user invoking maccat. |
| T-31-07 | Denial of Service | cli.py silent partial parse | mitigate | The ValueError guard in (OSError, ValueError) catch ensures a malformed .md (renamed .txt) exits immediately with a clear message — no partial reinstall.sh is written on format error |
| T-31-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase. stdlib-only. Package Legitimacy Gate does not apply. |
</threat_model>
