    - get_plist_version(path: Path) -> str
    - path does not exist → return ""
    - path is zero-byte file → return ""
    - path is a valid XML plist with CFBundleShortVersionString → return that string
    - path is a valid XML plist with no CFBundleShortVersionString but has CFBundleVersion → return CFBundleVersion
    - path is a valid XML plist with neither key → return ""
    - path is binary plist (plistlib handles both XML and binary natively) → return version string or "" per precedence rules
    - plistlib.load raises (e.g. InvalidFileException, OSError, PermissionError) → return ""
    - result is not a str (e.g. integer value in plist) → convert with str() or return ""
  </behavior>
  <action>
    Create src/maccat/helpers/plist_version.py. Module docstring must reference VER-03/VER-04 and
    note this helper is shared by SetappCollector and WebAppsCollector.

    Function signature: get_plist_version(path: Path) -> str

    Implementation steps (per 22-CONTEXT.md §.app version extraction decisions):
    1. Return "" immediately if not path.is_file() or path.stat().st_size == 0
    2. Open path in binary mode ("rb") and call plistlib.load() inside a try/except
    3. Catch Exception broadly (plistlib.InvalidFileException is a subclass; also
       catches OSError, PermissionError, struct.error from malformed binary plists)
    4. Key precedence: data.get("CFBundleShortVersionString") first;
       fall back to data.get("CFBundleVersion"); return "" if neither
    5. Coerce result to str() in case the plist value is numeric
    6. Return "" (empty string, not None) — callers use truthiness to detect absence

    Imports needed: from __future__ import annotations, import plistlib, from pathlib import Path

    Type hints must satisfy mypy --strict: the plistlib.load() return type is
    dict[str, Any], so annotate the data variable as dict[str, object].
    Use typing.cast or assert isinstance where necessary to satisfy strict mode without
    silencing errors with type: ignore unless truly unavoidable.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| brew subprocess output | Parsed line-by-line; malformed output degrades gracefully (name-only) |
| Info.plist file contents | Read from local filesystem only; plistlib parse errors caught |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Tampering | brew list --versions output | accept | split() parsing is defensive; malformed lines degrade to name-only; no shell=True |
| T-22-02 | Information Disclosure | plist version strings in catalog | accept | version strings are low-sensitivity config data; no secrets expected in CFBundleShortVersionString |
| T-22-03 | Denial of Service | plistlib reading large/malformed plist | mitigate | broad Exception catch in get_plist_version returns "" immediately; no unbounded reads |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | no new package installs in this plan; stdlib plistlib only |
</threat_model>
