```python
BASE = Path("/Applications/Setapp")

def collect(self) -> CollectorResult:
    entries: list[str] = [self.BASE.name]          # "Setapp"
    entries += [p.name for p in self.BASE.iterdir() if p.is_dir()]
    entries.sort()
    return CollectorResult(sections=[Section(title=self.TITLE, items=entries, raw=True)])
```

```python
BASE = Path("/Applications")

def collect(self) -> CollectorResult:
    entries: list[str] = [self.BASE.name]          # "Applications"
    for p in self.BASE.iterdir():
        if not p.is_dir(): continue
        if fnmatch.fnmatch(p.name, "Setapp*"): continue
        if fnmatch.fnmatch(p.name, "*App Store*"): continue
        entries.append(p.name)
    entries.sort()
    return CollectorResult(sections=[Section(title=self.TITLE, items=entries, raw=True)])
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /Applications filesystem | Read-only plist reads; errors caught; no writes |
| plistlib parse | Catches all exceptions; never propagates to collector |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-04 | Information Disclosure | CFBundleShortVersionString in catalog output | accept | version strings are public app metadata; not sensitive |
| T-22-05 | Denial of Service | Symlink loop in /Applications iterdir() | accept | iterdir() does not follow symlinks for is_dir() check; bounded by /Applications depth |
| T-22-06 | Tampering | Malicious CFBundleShortVersionString (e.g. injection chars) | accept | version string written as plain text to catalog; no execution path; no HTML/SQL context |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | no new package installs; stdlib plistlib only |
</threat_model>
