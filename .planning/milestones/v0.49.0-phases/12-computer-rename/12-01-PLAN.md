| T-12-03 | Denial of Service | menu input loop | accept | invalid input re-prompts indefinitely by design; EOF maps to clean Quit so a closed stdin cannot hang |
| T-12-SC | Tampering | npm/pip/cargo installs | mitigate | N/A — no package installs; pure Zsh edits to one existing file. No `[ASSUMED]`/`[SUS]` packages. |
