<objective>
Create a new `select_computer` Zsh function in `update-list.sh` that replaces the
behavior of the two legacy functions `get_target_location` and `resolve_machine_label`
with a single always-shown computer-folder menu. The function discovers existing
computer folders (union of folders containing catalogs + map values), marks this
Mac's remembered folder as the default, supports an Enter-default only when a
remembered folder exists, handles a "Create new computer" branch, a "Quit" option
(number / `q` / `quit` / EOF) that exits 0 cleanly, sets `TARGET_LOCATION`, and
upserts the hostname->folder map.

This plan ONLY ADDS the `select_computer` function (defined above the source-guard).
It does NOT delete the legacy functions or rewire the main block — that is Plan 02.
Both legacy functions remain in place and unreferenced-by-new-code after this plan;
the script still runs the old path until Plan 02 rewires it.

Purpose: Implements SEL-01..04 and the selection-menu half of QUIT-01.
Output: A sourceable `select_computer` function, isolated-testable via a mktemp fixture.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| interactive stdin → TARGET_LOCATION | A user-typed computer name becomes a directory name (`mkdir -p`) AND the catalog filename `[segment]`. Untrusted free text crosses here. |
| machine-labels.tsv → menu | Map values are read back and used as folder names / menu entries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | create-new name prompt in select_computer | mitigate | Route the create-new prompt through `validate_computer_name_quiet` in a re-prompt loop (rejects `/`, `[`, `]`, TAB, newline, leading/trailing whitespace) before `mkdir -p` / assignment. Same shared rule as the fatal flag path (Plan 02). |
| T-11-02 | Tampering | map read-loop in select_computer | accept | Map is a committed, repo-local file under the user's control; values originate from the same validated prompt. No external/network writer. TSV parse uses TAB-split + comment/blank skip consistent with existing loops. |
| T-11-03 | Information Disclosure | folder discovery glob | accept | Discovery only enumerates top-level dirs containing catalogs + map values; reads no file contents, no PII surface beyond existing repo. |
</threat_model>
