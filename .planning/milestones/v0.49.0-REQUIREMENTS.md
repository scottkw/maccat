# Requirements: Mac Software List Generator

**Defined:** 2026-06-14
**Milestone:** v0.49.0 Computer-Folder Model
**Core Value:** A single run produces one complete, restorable snapshot of a machine's software *and* tooling extensions — accurate enough to rebuild the environment from, degrading gracefully when any source isn't installed.
**Design:** `docs/superpowers/specs/2026-06-14-computer-folder-model-design.md`

## v1 Requirements

Requirements for milestone v0.49.0. Each maps to a roadmap phase.

### Computer Identity (CID)

- [x] **CID-01**: A new catalog saved into computer folder `X` is named `mac-software-list-[X]-YYYYMMDDHHMMSS.txt` — the `[...]` label segment equals the folder name (the raw hostname does not appear)
- [x] **CID-02**: A computer/folder name is an arbitrary user-chosen string (never derived from the hostname) and is validated — non-empty; rejects `/`, `[`, `]`, tab, newline, and leading/trailing whitespace; allows spaces, apostrophes, letters, digits, `-`, `_`, `.`
- [x] **CID-03**: The committed `machine-labels.tsv` maps hostname→computer-folder, and the script records/updates this Mac's chosen computer on each run so the menu can default to it

### Computer Selection (SEL)

- [x] **SEL-01**: Running interactively (no computer flag) presents a menu of the existing computer folders plus a "Create new computer" option and a "Quit" option
- [x] **SEL-02**: The computer this Mac last used is pre-selected as the default — pressing Enter accepts it; on a Mac with no remembered computer there is no Enter-default and the user must choose explicitly
- [x] **SEL-03**: Choosing "Create new computer" prompts for a name, creates that top-level folder, and uses it as this run's computer
- [x] **SEL-04**: Invalid input at the computer menu re-prompts instead of aborting, and an invalid name at the create-new prompt re-prompts instead of aborting

### CLI Flags (CLI)

- [x] **CLI-01**: `--computer "Name"` selects an existing computer or creates it, non-interactively (skips the menu)
- [x] **CLI-02**: `--personal`, `--office`, and `--machine "X"` continue to work as back-compat aliases — `--personal`/`--office` select those folders, `--machine "X"` behaves as `--computer "X"`

### Rename (RNM)

- [x] **RNM-01**: `--rename` presents a menu of existing computers (plus Quit), accepts a new name, and renames the chosen computer's folder including its `archive/` subfolder
- [x] **RNM-02**: A rename rewrites every catalog inside the folder (main + archive) to the new `[name]` by default, with an option to leave existing filenames unchanged
- [x] **RNM-03**: A rename updates the hostname→folder map entries and stages the folder moves, filename rewrites, and map update in a single git commit/push (honoring `--no-commit`); a no-match or no-op rename warns and exits without committing

### Menu Quit (QUIT)

- [x] **QUIT-01**: Every interactive menu (computer selection and the rename picker) offers a Quit option that exits cleanly (status 0) without writing a catalog or creating a commit

## Future Requirements

Deferred to future releases. Tracked but not in the current roadmap.

### Reinstall (RST)

- **RST-01**: Generate a reviewable `reinstall.sh` from a chosen catalog that reinstalls deterministic sources (Homebrew formulae/casks, Mac App Store apps, VS Code/Cursor extensions)
- **RST-02**: The generated script lists non-deterministic sources as a manual checklist rather than attempting to install them
- **RST-03**: The generated script is emitted for user review and is never auto-executed

### Deferred from prior milestones

- **CHR-02 / FF-02**: Capture browser-extension enabled/disabled state
- **CDX-02**: Catalog Codex plugins once that subsystem ships

## Out of Scope

Explicitly excluded for v0.49.0. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Auto-migrating existing mixed-label files on a normal run | Existing `[hostname]` files are aligned only via an explicit `--rename` (rewrite-all option), not silently on every run |
| Renaming the `machine-labels.tsv` file itself | Keep the filename to avoid extra churn; only its meaning (hostname→computer) changes |
| Changing catalog *content* (the software sections) | This milestone changes identity/folders only; the cataloged sections are untouched |
| Reinstall / restore from a catalog | The planned next milestone |
| Cross-platform support (Linux/Windows) | macOS/Zsh-only by design (BSD `date -v`, `/Applications`, browser paths) |
| Rewriting the script's architecture (globals-as-parameters, etc.) | Bolt new behavior onto existing conventions rather than refactor |
