<objective>
Change the Homebrew catalog section so it records only **user-installed (top-level)** formulae
instead of every installed formula including transitive dependencies.

`brew leaves` gives exactly that set, but prints **names only** — no versions. The catalog
contract requires versions (VER-01/VER-02) and `brew`-returned ordering (VER-06), so the fix is an
**intersection**: keep running `brew list --formula --versions` as the source of truth for line
content and ordering, and use the `brew leaves` name set purely as a filter.

Casks are out of scope for the filter — `brew leaves` covers formulae only, and cask behaviour must
stay byte-identical.

Purpose: a catalog that reflects what the user actually chose to install, so the reinstall script
re-installs intent rather than a dependency closure (Homebrew resolves dependencies itself on
install, so nothing is lost by dropping them from the catalog).
Output: a filtered formula list in the existing `Homebrew Packages` section; no format change, no
new section, no signature change on the collector's public API.
</objective>
